Student Transport Route Optimization

Capacity-Constrained K-Means Clustering for Scalable School Bus Route Planning

An analytics-driven transportation optimization project that uses Python and Capacity-Constrained K-Means Clustering to optimize student-to-bus allocation, reduce operational requirements, and automate route assignment for new students.

Project Overview

Managing school transportation becomes increasingly complex as student enrollment grows. Manual route allocation can lead to inefficient bus utilization, unnecessary operating costs, and significant workload for transport managers.

This project develops a data-driven route optimization system to assign students to transportation routes while considering bus capacity and operational constraints.

The solution was designed for a transportation network serving:

710 students

21 existing routes

Multiple geographic locations

Fixed bus capacity constraints

Continuous addition of new students

Using clustering-based optimization, the system identified an opportunity to consolidate operations from 21 to 19 buses, with a potential annualized saving of approximately ₹50 Lakhs.
